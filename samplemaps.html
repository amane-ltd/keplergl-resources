スターターマップ詳細

Kepler.glで利用可能なJSON形式のスターターマップ。

利用手順

  1. 読み込みしたいスターターマップのURLをコピー
  2. Kepler.gl を開く
  3. 「Layers / レイヤ」タブを開く
  4. ポップアップ内の「Load Map using URL」タブをクリック
  5. コピーしたURLをペースト
  6. 緑色の「Fetch」をクリック

スターターマップ

全国スターターマップ

URL

https://raw.githubusercontent.com/amane-ltd/keplergl-resources/refs/heads/main/samplemaps/samplemap.json

概要

全国を対象に、交通（鉄道・バス・シェアサイクル）、人口（メッシュ・町丁目）、都市計画（用途地域・区域区分）、3D都市モデルまで幅広いデータを収録したスターターマップ。地域分析や現況把握の起点として利用できる。

データ一覧

  • 鉄道駅
  • 鉄道路線
  • バス停
  • バス路線
  • シェアサイクルステーション
  • 道路ネットワーク
  • メッシュ人口
  • 町丁目人口
  • 都市計画用途地域
  • 都市計画区域区分
  • 3D都市モデル（PLATEAU 2023 LOD0）
  • 市区町村境界

ベースマップ

レクチャー用スターターマップ

URL

https://raw.githubusercontent.com/amane-ltd/keplergl-resources/refs/heads/main/samplemaps/lecturemap.json

概要

鉄道・バスなどの交通データとメッシュ人口に絞って収録した、レクチャー・研修向けのスターターマップ。基本的な地図操作やデータ可視化を学ぶ入門用途に適する。

データ一覧

  • 鉄道駅
  • 鉄道路線
  • バス停
  • バス路線
  • メッシュ人口
